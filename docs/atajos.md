# Atajos de teclado

La misma lista está dentro de Orbital: **Atajos de teclado** (`Ctrl+?`). Todas las acciones
también están en la **paleta de comandos** (`Ctrl+Mayús+P`).

## Bóveda y ventana

| Acción | Atajo |
|---|---|
| Abrir una carpeta | `Ctrl+O` |
| Abrir como bóveda de Orbital | `Ctrl+Mayús+O` |
| Nota nueva | `Ctrl+N` |
| Diario de hoy | `Ctrl+Alt+D` |
| Saltar a una nota (selector rápido) | `Ctrl+P` |
| Paleta de comandos | `Ctrl+Mayús+P` |
| Buscar en toda la bóveda | `Ctrl+Mayús+F` |
| Mostrar u ocultar la barra izquierda / derecha | `Ctrl+[` / `Ctrl+]` |
| Mostrar u ocultar los retroenlaces | `Ctrl+Mayús+B` |
| Galería de la nota en la barra derecha | `Ctrl+Alt+G` |
| Preferencias | `Ctrl+,` |
| Atajos de teclado | `Ctrl+?` |

## Nota abierta

| Acción | Atajo |
|---|---|
| Vista Código / Lectura / Dividida | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` |
| Buscar en la nota / reemplazar | `Ctrl+F` / `Ctrl+H` |
| Deshacer | `Ctrl+Z` |
| Editar la ecuación del cursor o insertar una | `Ctrl+M` |
| Pegar una imagen como adjunto | `Ctrl+Mayús+V` |
| Exportar la nota como HTML | `Ctrl+Mayús+E` |
| Archivar la nota | `Ctrl+Mayús+A` |
| Renombrar o mover la nota | `F2` |
| Mover la nota a la papelera | `Supr` |

## Editor (vista Código)

| Acción | Atajo |
|---|---|
| Plegar / desplegar el elemento | `Ctrl+↑` / `Ctrl+↓` |
| Enfocar el elemento / subir un nivel en el enfoque | `Alt+→` / `Alt+←` |
| En una lista: seguir la lista | `Enter` |
| En una lista: sangrar / quitar sangría (con sus subítems) | `Tab` / `Mayús+Tab` |
| En una lista: mover el ítem con sus subítems | `Alt+↑` / `Alt+↓` |
| Agregar un cursor | `Alt+clic` o `Alt+arrastre` |
| Agregar un cursor arriba / abajo (por columnas) | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| Volver a un solo cursor | `Esc` |
| Autocompletado: elegir / aceptar / cerrar | `↑` `↓` / `Enter` o `Tab` / `Esc` |

## Galería de la nota

| Acción | Atajo |
|---|---|
| Recorrer títulos y mosaicos | flechas |
| Plegar o desplegar un grupo; abrir el visor | `Enter` |
| Ir al embed en el editor | `Ctrl+Enter` |
| Menú del mosaico | `Mayús+F10` |
| En el visor: ir al embed / información del archivo / cerrar | `E` / `I` / `Esc` |
