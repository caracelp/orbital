# Documentación de Orbital

## Para usar Orbital

- [Atajos de teclado](atajos.md): la lista completa, por tema.
- [Sincronizar con Google Drive](google-drive-proyecto.md): crear tu proyecto de Google Cloud
  (una sola vez, unos 15 minutos) y conectar la bóveda.

## Formato de la bóveda

- [Formato en disco de una bóveda](formato-boveda.md): la estructura `raw/` + `wiki/`, las
  propiedades, los enlaces, los archivos de `.orbital/` y la sintaxis de cada bloque (fórmulas,
  gráficos, diagramas, carruseles, galerías, consultas, conexiones con tipo, tarjetas de
  estudio…). Es la referencia para cualquier herramienta que quiera leer o escribir la misma
  bóveda.
- [Formato de las bases](formato-base.md): los archivos `.base`.
